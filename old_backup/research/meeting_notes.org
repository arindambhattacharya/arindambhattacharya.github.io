** [2020-02-19 Wed]
**** Positive/Negative Agreement method
     - Separately calculate negative and positive region intervals
     - Separate agreement parameters for agreement of both positive and negative points
     - For a training point, classify it as positive if:
       - The number of dimensions saying it is positive is *greater* than positive agreement threshold and number of dimensions saying it is negative is *less* than negative agreement threshold
**** Relational Agreement method
     - Separately calculate negative and positive region intervals
     - Single ratio parameter
     - For a training point, classify it as positive if:
       - The ratio of (number of dimensions classfying it as negative) to (number of dimensions classfying it as positive) is less than ratio parameter

***** [[file:random_kernal/oneclassRFF/error_anal.html][Error Analysis]]
***** On the usefulness of one-class classifier ensembles for decomposition of multi-class problems [[file:papers/decomposition%20of%20multi-class.pdf][pdf]]
      - Traditional multi-class solutions: OVO, OVA
      - Using OCC for multi-class decomposition: different fusion methods:
	- Untrained method:
	  - Max decision function value (same as ours)
	  - Pairwise Coupling. Calculating pairwise probability and assigning class with maximum posterior probability
      - Conclusions for using OCC for multi-class decomposition:
	- Not a universal solution. For standard data, binary decomposition is better. For some complex data OCC is "worthwhile direction".
	- Works very well when high number of classes. OVO has n choose 2 classifiers and OVA suffers from class imbalance.
	- Can deal with "difficult data" better. These include: imbalanced distribution, noisy features and labels, and small amount of data.
	- Difference between different OCC models is small. Can use ensembles with different OCC.
