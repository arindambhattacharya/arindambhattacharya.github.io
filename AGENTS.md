# Project Notes

## old_backup/ — Future Integration

The `old_backup/` directory contains an older version of the website, predating the Wowchemy/Academic site. It is currently deployed as-is at `/old_backup/` and is **not yet integrated** into the main site.

### Contents

- `reading/` — a reading list page with custom CSS
- `research/` — research notes, meeting notes, paper lists, and plots exported from org-mode
- `rlrg/` — RL reading group page
- `org-html-themes/` — CSS themes used for org-mode HTML export
- `setup/` — org-mode export setup files

### Integration Plan

Eventually these pages should be linked from the main Wowchemy academic site — either as standalone pages in the nav, or migrated into the Hugo/Wowchemy content structure. No work has been done on this yet.
